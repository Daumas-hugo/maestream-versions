# Maestream : les versions

Les installeurs de Maestream, et le fichier que l'appli lit pour savoir s'il en existe une plus récente.

- **Installer** : prends le `Maestream_…_x64-setup.exe` de la [dernière version](../../releases/latest).
- **Mettre à jour** : l'appli le propose d'elle-même, en haut de l'écran, quand une nouvelle version est publiée ici.

Chaque installeur est signé : l'appli refuse une mise à jour qui ne vient pas de cette signature.

Le code de Maestream n'est pas ici.
